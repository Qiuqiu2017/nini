# 你你 · 挤语 (nini)

两个「你」挤在同一个终端里聊天，边聊边把中文**一步步挤成一种新语言**。

没有大模型，没有网络请求：全程由一个纯 Python 的「挤语引擎」驱动。
你可以围观他们造词、吵架、和好，也可以随时按 Enter 加入聊天、打断他们、
甚至把你说的话塞进他们的字典里。

## 快速开始

```bash
git clone https://github.com/Qiuqiu2017/nini
cd nini
./run.sh            # 或 python3 -m nini
```

零依赖，只需要 Python 3.9+。

```
tè～啾: 窝系tè～啾, 窝负责把词挤短。
díulō～鸭: 窝宣布!「你好」从今以后就叫「be～啾」!
tè～啾: 行叭, 挤进字典。
díulō～鸭: 窝宣布!「谢谢」从今以后就叫「nǔzhī～叽」!
tè～啾: 行叭, 挤进字典。
你: 你们聊到哪啦?
tè～啾: 泥挤过来讲, 窝认真听。
díulō～鸭: 泥吼这个词还能挤得更短!
    (中文) 你好这个词还能挤得更短!
```

## 玩法

- **两个「你」**：左边那位负责造新词，右边那位负责把词挤短，性格不同，会拌嘴。
- **语言进化**：词典里有 150 个常用词 + 10 条语法规则，分 10 个纪元逐步生效：
  语气粒子、的→嗝、吗→咩、动词叠字、副词后置、系可以挤掉、
  双音节词压缩成「头+挤」……最终中文被挤成句尾统一「～咩啾」的新语言。
- **你可以打断**：随时按 `Enter` 说话，他们立刻回应；
  `Esc` 能把他们打到一半的话瞬间逼出来。
- **喂词**：你说出的陌生词有概率被他们当场改造收编（「奶茶」→「茶奶奶」式）。
- **挤一挤**：聊到「挤」时，两块面板真的会互相挤，字会漏到隔壁去。
- **存档**：进度自动存到 `~/.config/nini/state.json`，下次打开接着挤。

## 按键

| 按键 | 作用 |
| --- | --- |
| `Enter` | 开口说话 / 发送 |
| `Esc` | 打断当前说话（瞬间说完）/ 取消输入 |
| `T` | 开关中文翻译字幕 |
| `P` | 暂停 / 继续自动聊天 |
| `S` | 立即存档 |
| `R` | 重置语言，从头再挤一遍 |
| `Q` | 退出（自动存档） |

## 其它玩法

```bash
python3 -m nini --demo 80     # 非交互演示 80 条消息（适合截图/管道）
python3 -m nini --seed 42     # 固定随机种子
python3 -m nini --reset       # 清除存档重新开始
python3 -m nini --check       # 自检
```

## 原理

`nini/conlang.py` 是挤语引擎：按纪元维护「中文 → 挤语」词典和语法规则，
生成带声调的随机音节词（mī、nú、qǐu…），并按规则后处理句子。
`nini/brain.py` 是两个「你」的大脑：闲聊模板、造词仪式、纪元公告、
用户关键词反应与「收编用户词汇」。`nini/ui.py` 是 curses 界面，
包含打字机效果、双栏气泡和挤来挤去的分栏动画。
